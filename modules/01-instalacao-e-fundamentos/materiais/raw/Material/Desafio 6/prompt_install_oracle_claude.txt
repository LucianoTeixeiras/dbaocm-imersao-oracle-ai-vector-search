Você é um engenheiro DBA especialista em Oracle. Sua tarefa é automatizar completamente a preparação de um Oracle Linux 8.10 ARM64 rodando em VMware Fusion no MacOS com chip Apple Silicon, e em seguida instalar o Oracle Database 19c.
Contexto do ambiente:

Host: MacOS com arquitetura ARM (Apple Silicon)
Hypervisor: VMware Fusion
Guest OS: Oracle Linux 8.10 (já instalado e acessível via SSH)
Arquitetura da VM: ARM64
IP da VM: 192.168.18.220
Arquivo do instalador Oracle está na pasta Downloads da minha maquina local

O que você deve fazer:

Conectar na VM via SSH como root
Configurar o /etc/hosts com hostname lab-imersao-19c.localdomain
Instalar o pacote oracle-database-preinstall-19c via yum
Definir senha do usuário oracle
Configurar IP estático na interface ens160
Desabilitar SELinux
Parar e desabilitar o firewalld
Criar os diretórios /u01/app/oracle/product/19.0.0/dbhome_1 e /u02/oradata com as permissões corretas para o usuário oracle:oinstall
Descompactar o instalador do Oracle no ORACLE_HOME
Executar a instalação silenciosa do Oracle Database 19c Enterprise Edition com as seguintes definições:

ORACLE_BASE: /u01/app/oracle
ORACLE_HOME: /u01/app/oracle/product/19.0.0/dbhome_1
Global database name: orcl.localdomain
SID: orcl
PDB: orclpdb
Character set: AL32UTF8
Data location: /u02/oradata


Executar os scripts root.sh e orainstRoot.sh automaticamente após a instalação
Configurar as variáveis de ambiente do Oracle no .bash_profile do usuário oracle
Habilitar o início automático do banco no /etc/oratab
Criar e habilitar um serviço systemd para o Oracle Database
Validar a instalação conectando via sqlplus e consultando a v$instance

Requisitos:

Use os tools de bash do Claude Code para executar cada etapa via SSH na VM
Valide o sucesso de cada etapa antes de prosseguir para a próxima
Em caso de erro em qualquer etapa, pare e informe o problema com detalhes
Ao final, exiba um resumo com o status da instalação, versão do banco, nome da instância e a URL do Oracle EM Express
