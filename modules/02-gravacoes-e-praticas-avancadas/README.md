# Módulo 02 — Imersão Oracle Database com IA - Gravações e Práticas

> **Programa:** Imersão Oracle Database com IA — G. A. R de Brito Educacao
> **Trilha:** DBA / Engenharia de Banco de Dados e Inteligência Artificial

## Ementa do Módulo

Acompanhamento das aulas gravadas, resolução de dúvidas da comunidade e integração com IA.

## Competências Desenvolvidas

- Aplicar conceitos práticos demonstrados nas aulas ao vivo e gravações
- Integrar fluxos de banco de dados com recursos de IA
- Diagnosticar e solucionar problemas comuns reportados na comunidade

## Estrutura

| Pasta | Conteúdo |
| :--- | :--- |
| `aulas/` | Apostilas técnicas e cadernos de aula sintetizados |
| `labs/` | Exercícios práticos, notebooks e scripts de laboratório |
| `materiais/raw/` | Materiais brutos originais (PDFs, slides, handouts) |
| `materiais/transcricoes/` | Transcrições processadas pelo knowledge-extractor |
| `portal/` | Catálogo de aulas (`catalogo.md`) e espelho do AVA |
